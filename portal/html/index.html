支持协议： VLESS-Reality Shadowsocks-2022 Trojan VMess   看 4 协议对比 →

注意：可能无法使用的场景

  • Netflix HD/4K ── Hetzner 数据中心 IP 被 Netflix 标记，多半会显示"检测到 VPN 解锁工具"，看不了 HD。能解锁的是 480p 兜底（无 DRM 资源）。
  • Disney+ / HBO Max / Hulu ── 同上，数据中心 IP 多半被屏。
  • iCloud Private Relay / Apple 隐身中继 ── 苹果系统设置层面优先，与本 VPN 同开会绕过。
  • P2P / BitTorrent 大流量 ── 不禁，但管理员保留追查能力，请别下盗版。
  • 境内某些银行/政务 App ── 走 VPN 时部分国内 App 拒服务（GeoIP 风控），用时请关 VPN。

可以正常使用：YouTube / Twitter / Discord / GitHub / Reddit / Spotify / Twitch / 暗网 Tor / 海外学习平台 / 海外 SaaS。

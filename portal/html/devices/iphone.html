iPhone / iPad 接入指南

苹果原生支持 IKEv2，连 App 都不用装！

推荐方案：原生 IKEv2 描述文件

简单 30 秒 ~ 1 分钟 零 App（推荐）

iPhone 和 iPad 系统自带 IKEv2 VPN 协议。你只需要点一下我们发给你的 描述文件链接，系统会引导你安装一个 .mobileconfig 配置文件，整个过程不超过 30 秒，连 App Store 都不用打开。

去「我的账户」拿订阅

  1. 用 Safari（必须 Safari）打开订阅链接

    把上面那条 URL 复制到 iPhone 自带的 Safari 浏览器打开。注意不要用微信 / 抖音内置浏览器，那些会拦截描述文件。

  2. 允许下载配置描述文件

    Safari 会弹出"此网站正在尝试下载一个配置描述文件"，点 允许。然后系统提示"描述文件已下载"，点 关闭。

  3. 打开 设置 → 已下载描述文件

    回到桌面，打开"设置"。最上面（你的 Apple ID 下方）会出现一个新的条目"已下载描述文件"，点进去。

  4. 安装描述文件

    右上角点 安装，输入你的 iPhone 锁屏密码，再点一次 安装。完成后点 完成。

  5. 开启 VPN

    回到"设置"主页，往下滑找到 VPN（或"通用 → VPN与设备管理"，iOS 版本不同位置不同），把开关打开。状态栏会出现 VPN 图标。

  6. 测试是否成功

    Safari 打开 https://ipinfo.io，看看 country 是不是 DE (Germany)、city 是不是 Frankfurt。是的话恭喜你，已经在德国岛了！DE

常见问题

装完描述文件，VPN 开关一开就自动关？

多半是网络不通到德国 IP。在墙内国家使用 IKEv2 可能被 ISP 干扰，请尝试切换 WiFi/4G，或改用 VLESS-Reality 方案。

状态栏有 VPN 图标但还是上不了 Google？

用 Safari 访问 ipinfo.io，如果 IP 已经是德国 IP 但 google.com 仍然慢，可能是 DNS 缓存。在"设置 → 通用 → 还原 → 还原网络设置"试一次。

Safari 不让我下描述文件？

不能用微信/QQ/抖音内置浏览器！必须用系统自带 Safari。把链接复制到 Safari 重新打开。

如何卸载？

设置 → 通用 → VPN与设备管理 → 选中描述文件 → 移除描述文件。

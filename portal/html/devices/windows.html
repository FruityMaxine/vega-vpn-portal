简单 2~5 分钟

Clash Verge Rev 安装步骤

  1. 下载 Clash.Verge_x.x.x_x64-setup.exe

    GitHub Releases 页面找最新版的 Windows setup 安装包，双击安装。安装时 Windows Defender / SmartScreen 可能拦截，点"更多信息 → 仍要运行"。

  2. 启动 Clash Verge → 同意管理员权限

    需要管理员权限以便设置系统代理 / TUN 网络驱动。

  3. "订阅"页 → 点 + → URL 模式 → 粘贴 Clash 订阅 URL

  4. "代理"页 → 选你的德国节点

    顶部模式选 Rule 规则（国内直连，国外代理）。

  5. "设置"页 → 开启"系统代理" + "TUN 模式"

    TUN 模式会安装 wintun.dll 驱动，让所有应用（包括 Steam、Discord、游戏）都走代理。

  6. 测试

    浏览器打开 ipinfo.io，看到德国 IP 即成功。或访问 fast.com 测速。

NekoRay（极客版）

NekoRay 是给老玩家用的，UI 复古、内核可在 v2ray-core / Xray-core / sing-box 之间切换。适合自己改路由规则的人。

  1. 下载 nekoray-x.x.x-windows64.zip

    解压到任意目录（比如 C:\nekoray\），双击 nekoray.exe 启动。

  2. 程序 → 添加 → 从剪贴板导入分享链接

    或用"订阅组 → 新建 → 类型: sing-box / clash"。

  3. 程序 → 模式 → 系统代理 / TUN 模式 二选一

Hiddify（一键派）

Hiddify 是 sing-box 团队官方推荐的 GUI，跨平台一致体验。装好直接粘订阅，一键连接，零配置。

  1. 下载 Hiddify-Windows-Setup-x.x.x.exe → 安装

  2. 主界面点"添加配置" → 粘贴 sing-box 订阅 URL

  3. 大按钮"启动" → 自动选最快节点

备用：Windows 原生 IKEv2

不想装第三方？Windows 10/11 自带 IKEv2 客户端，但需要手动配 server / 账号密码。我们可以提供 IKEv2 凭据（请向管理员索取）。

  1. 设置 → 网络和 Internet → VPN → 添加 VPN

  2. VPN 提供商：Windows (内置)

  3. 连接名称：Vega-DE

  4. 服务器地址：vpn.example.com

  5. VPN 类型：IKEv2

  6. 登录信息类型：用户名 + 密码 → 填管理员发的账号

  7. 保存 → 点连接

常见问题

Defender 把 Clash Verge 删了？

开 Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加 %LOCALAPPDATA%\Programs\Clash Verge 整个文件夹。代理软件被误报是常态。

TUN 模式开不了？

(1) 用管理员权限运行 Verge；(2) 装 wintun.dll 驱动（Verge 安装时会装，可能被杀软删了）；(3) Windows 防火墙允许 Verge 通过。

系统代理开了浏览器没生效？

看一下 IE 代理设置（控制面板 → Internet 选项 → 连接 → 局域网设置），HTTP 代理应为 127.0.0.1:7897。如果 Chrome 装了 SwitchyOmega 等扩展，会覆盖系统代理。

游戏 / Steam 不走代理？

开 TUN 模式，TUN 是网卡层代理，所有 TCP/UDP 包都走，包括游戏。或者在 Verge 路由规则里把游戏域名加进代理列表。

开机自启动？

Verge → 设置 → "开机启动" + "静默启动" 都打开。

到这一步需要你的订阅链接 / 二维码？

所有订阅都在「我的账户」里管理（含多个订阅时可自选）。点下面按钮跳过去复制 URL 或扫二维码。

去「我的账户」拿订阅

  1. 下载并安装 v2rayNG.apk

    从 GitHub Releases 下载 v2rayNG_x.x.x_arm64-v8a.apk（99% 现代安卓手机选这个 arm64 版）。下载后会提示"安装未知来源应用"，到设置里允许即可。

  2. 打开 v2rayNG → 右上角 + → "从剪贴板导入批量 URL"

    先把上面那条订阅 URL 复制到剪贴板（点按钮），再点 App 里的"从剪贴板导入"。或选"订阅设置" → 添加，把 URL 粘进 URL 字段。

  3. 点右上角 ⋮ → 更新订阅

    会拉取节点列表。等几秒，主界面会出现一个或多个"Vega-DE-…"节点。

  4. 选中节点 → 右下角 V 图标 → 启动

    系统第一次会弹"VPN 请求"，点确定。状态栏会出现钥匙图标 表示已连接。

  5. 测试：浏览器打开 ipinfo.io

    看到 DE / Frankfurt 即成功。或访问 youtube.com 看能否打开。

常见问题

装 APK 时提示"不允许安装来历不明应用"？

设置 → 应用 → 浏览器（你下载 APK 的浏览器）→ 高级 → 安装未知应用 → 打开。或全局：设置 → 安全 → 安装未知应用。

连接后没网络？

检查节点延迟（v2rayNG 主界面右上角"测试当前节点延迟"），如果超时，可能是 IP 被墙。换 Hysteria2 / Reality 协议（NekoBox 方案）。

状态栏 VPN 图标在，但 YouTube 还是连不上？

(1) 关 v2rayNG 重开；(2) 检查 v2rayNG "设置 → 路由模式 = 绕过局域网及大陆"；(3) 清 YouTube App 缓存。

小米 / 华为机型连不上？

厂商系统会杀后台 VPN。把 v2rayNG 加到"省电策略 → 无限制"白名单 + "自启动"白名单。

分应用代理怎么开？

v2rayNG → 设置 → "每应用代理模式" 开启 → 选只代理 Chrome / YouTube / TG 等，国内 App 不走代理。

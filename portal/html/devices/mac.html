Mac · macOS 接入指南

Intel / Apple Silicon 全支持，三种方案任选！

方案 A：原生 IKEv2（最省事）

简单 1~5 分钟

和 iPhone 一样，macOS 内置 IKEv2 客户端，**完全不用装第三方 App**。我们提供 .mobileconfig 描述文件，双击就能装。

专属订阅链接：

到这一步需要你的订阅链接 / 二维码？

所有订阅都在「我的账户」里管理（含多个订阅时可自选）。点下面按钮跳过去复制 URL 或扫二维码。

去「我的账户」拿订阅

  1. 在 Safari 里打开上面的描述文件 URL

    会下载一个 .mobileconfig 文件到下载目录。

  2. 双击下载的 .mobileconfig 文件

    macOS 会提示"已下载描述文件 Vega-IKEv2"。打开 系统设置 → 隐私与安全性 → 描述文件（旧版 macOS 在"系统偏好设置 → 描述文件"）。

  3. 选中 Vega-IKEv2 → 点"安装" → 输入 Mac 登录密码

  4. 菜单栏图标连接

    安装完成后，菜单栏右上角会出现 VPN 图标（或在"系统设置 → 网络"里看到 Vega-VPN 条目）。点一下选择"连接"即可。

  5. 测试：浏览器打开 ipinfo.io

    看到德国 IP 即成功。

优点：零依赖、开机自动连（可在网络设置里勾"自动连接"）、超低 CPU 占用。
缺点：遇到网络环境严苛时 IKEv2 可能不稳定，那时用方案 B/C。

方案 B：ClashX Pro / Clash Verge Rev

中等 3 分钟 需下载 App

ClashX Pro 是 macOS 上最流行的代理 GUI。原版 ClashX 已停更，推荐 Clash Verge Rev（活跃维护、支持 Apple Silicon 原生）。

Clash Verge Rev · Apple Silicon (本地镜像) Clash Verge Rev · Intel x64 (本地镜像) Hiddify macOS (本地镜像) 原始 GitHub（需已有梯子） 免费开源 · macOS 12+ · M1/M2/M3/M4 选 aarch64，Intel 选 x64
Clash Verge Rev · 本地镜像Apple Silicon · 推荐
mihomo (内核)底层 · 已内置在 Verge

你的 Clash 订阅：

到这一步需要你的订阅链接 / 二维码？

所有订阅都在「我的账户」里管理（含多个订阅时可自选）。点下面按钮跳过去复制 URL 或扫二维码。

去「我的账户」拿订阅

  1. 从 GitHub Releases 下载 .dmg 安装包

    Apple Silicon (M1/M2/M3/M4) 选 aarch64，Intel Mac 选 x86_64。把 Verge 拖到 Applications。

  2. 首次启动 → 同意管理员权限（用于设置系统代理）

  3. 左侧"订阅" → 点 + → 粘贴 URL

    把上面 Clash 订阅 URL 贴进去，点导入。等几秒会显示节点列表。

  4. "代理"页 → 选中你的德国节点

    顶部"模式"建议选 规则 (Rule)，国内站点直连、国外走代理。也可以选 全局 (Global) 强制全走。

  5. 开启"系统代理"开关 + "TUN 模式"开关

    TUN 模式可以代理那些不走系统代理的 App（比如 Telegram）。开 TUN 时会请求安装 helper，给权限即可。

方案 C：sing-box CLI（极客）

复杂 10 分钟 命令行

如果你喜欢命令行、想做 launchd 自启、或者要在脚本里用，可以直接跑 sing-box。

brew install sing-box 需先装 Homebrew (brew.sh) 
# 用 Homebrew 装
brew install sing-box

# 下载你的配置（用 token 替换）
curl -L "<在 我的账户 页面复制你的订阅URL>" -o ~/.config/sing-box/config.json

# 跑
sudo sing-box run -c ~/.config/sing-box/config.json

需要自启的可以写一个 launchd plist 到 ~/Library/LaunchAgents/com.vega.singbox.plist，然后 launchctl load。

常见问题

双击 .mobileconfig 没反应？

macOS Ventura 之后描述文件不会自动弹安装窗口，要去"系统设置 → 隐私与安全性 → 最下面有描述文件"里手动安装。

ClashX 开了，浏览器还不走代理？

看一眼 macOS"系统设置 → 网络 → 你的 WiFi → 详细信息 → 代理"那一栏，HTTP/HTTPS 代理是不是指向 127.0.0.1:7890。如果不是，ClashX 没成功设系统代理，重启 App 重试。

Apple Silicon Mac 跑出"已损坏"？

开终端跑 sudo xattr -rd com.apple.quarantine /Applications/Clash\ Verge.app 解除隔离标记。

怎么测速？

Verge 节点列表右边有 闪电图标，点一下测延迟。或访问 fast.com 看带宽。

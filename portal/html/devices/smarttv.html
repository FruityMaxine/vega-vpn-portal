简言之：除非你的电视是 Android TV / Google TV 内核（能装 APK），否则都得走"路由器层 VPN"。

推荐方案：路由器层 VPN

把 VPN 装在路由器上，整个家里 WiFi 都自动走 Vega，电视只要连 WiFi 就有了德国 IP。这是封闭电视系统的唯一可行方案。

跳到路由器教程 京东搜 GL.iNet 旁路由 改走 Android TV 棒 (HDMI 盒子) 三星/LG/华为/海信无法直装 · 用路由器或外接盒子

完整流程见 路由器配置页。这里给一个最简单方案（"小白盒子"旁路网关）：

  1. 买一台 GL.iNet 旅游路由器

    推荐：GL-MT3000（Beryl AX，约 380 元）。开箱即用，Web 后台原生支持 V2Ray / sing-box。如果只用来给一台电视，更便宜的 GL-MT300N（120 元）也行。

  2. 用网线把这台小路由的 WAN 口连到你家主路由的 LAN 口

    或者让小路由 WISP 连接到你家 WiFi（旅行路由模式），两种都可以。

  3. 电脑 / 手机连小路由的 WiFi（默认 GL-MT3000-xxxx）

    浏览器打开 http://192.168.8.1 进入管理后台。设默认密码。

  4. "应用程序 → V2Ray / Sing-Box" → 粘贴你的订阅 URL

    到这一步需要你的订阅链接 / 二维码？

    所有订阅都在「我的账户」里管理（含多个订阅时可自选）。点下面按钮跳过去复制 URL 或扫二维码。

    去「我的账户」拿订阅

    导入后选你的德国节点，启动透明代理。

  5. 把电视的 WiFi 切到小路由的 SSID

    三星 / LG / 华为 / 海信 → 设置 → 网络 → 选小路由 WiFi → 输密码 → 连接。

  6. 测试

    电视上多数没有浏览器。可装一个 "WhatsMyIP" / "Speedtest" App（应用商店里大多有），看 IP/位置是否变德国。或直接打开 YouTube App 看推荐内容是否变成英文 + 德国。

进阶：如果你想只让电视走 VPN，其他设备直连，在小路由的 PBR 规则里按 MAC 地址只对电视开代理，其他设备走直连。这样下载、刷抖音都不受影响。

各品牌特殊说明

三星 Tizen OS

Tizen 完全不允许第三方 VPN，Smart Hub 里只有几款官方合作 VPN App（NordVPN / ExpressVPN 等付费商业 VPN），不接受自定义订阅。唯一方案是路由器层。三星电视有"开发者模式"可侧载，但只能装 Tizen App，没有 V2Ray 客户端的 Tizen 移植，所以走不通。

LG webOS

同三星，webOS 是封闭系统。必须路由器层。LG TV 自带浏览器，可以用浏览器访问 ipinfo.io 验证。

华为鸿蒙智慧屏（国行）

国行华为电视的鸿蒙系统不开放侧载 + 默认禁用谷歌服务。配置完路由器层后，很多境外应用（YouTube App / Netflix App）也无法直接安装，只能用浏览器看。如果你买了海外行货华为电视（Vision S 等）则可用 Google Play 装 App。

海信 Vidaa OS

海信全球版用 Vidaa OS（自研），不可装 VPN App。路由器层 + 海外行货才有 Netflix/Disney+ App。

索尼 Bravia / TCL Google TV / 小米电视

这些都是 Android TV / Google TV 内核，可以直接侧载 v2rayNG / NekoBox。直接看 Android TV 教程，无需路由器层。

Roku TV / Fire TV Stick

Roku 完全封闭，无侧载。Fire TV（亚马逊 Fire OS，基于 Android）可侧载 v2rayNG（看 Android TV 教程），但 Amazon 应用商店里没有，要 ADB 装。

常见问题

Netflix 在三星 / LG 上提示"代理检测"？

家用 VPS IP 大概率已被 Netflix 标记。让管理员切换出口 IP 到德国住宅 IP 池，或者用 Hysteria2 协议 + 较冷门端口。

电视上能看到德国 IP 但 Netflix 还是中国库？

(1) 在电视 Netflix App 里登出再登入；(2) Apple ID / Netflix 账号绑定的国家会影响内容库，不是 IP 一变就立刻切；(3) DNS 也要走 VPN，路由器要劫持 DNS 到代理。

YouTube TV / Hulu / Disney+ 类似问题？

同上。Hulu 对 VPN 检测最严，需要专门的"住宅 IP"中转。Vega 默认配的家用 VPS 多数能过 YouTube / Disney+，但 Hulu 可能不行。

路由器走 VPN 后家里其他设备变慢？

用 PBR 规则只对电视走代理，或买双频路由器分两个 SSID：一个走 VPN（接电视）一个直连（手机用）。

电视没有应用商店，怎么装新 App？

三星 / LG 不能装任何 App。鸿蒙 / Vidaa 偶尔可以在系统的"应用市场"找到（国行限定）。最便捷的办法：买个 Apple TV 4K 或 Onn 4K Pro 接 HDMI 当机顶盒。

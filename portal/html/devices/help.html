三步排查法

  1. ① 看图标 — VPN 真的连上了吗？

    iPhone 状态栏顶部有 VPN 字样吗？Android 有钥匙图标吗？Mac 菜单栏图标变了吗？没看到代表客户端没启动或权限被拒。

  2. ② 看 IP — 出口真的变德国了吗？

    浏览器打开 https://ipinfo.io。
    看到 country: DE + city: Frankfurt → 代理生效；
    还是你的本地 IP → 系统代理 / TUN 没开（看下面对应平台问题）。

  3. ③ 看延迟 — 节点是否健康？

    每个客户端都有"测延迟"按钮。健康节点 < 300ms，超过 500ms 大概率出口拥塞或被封。换协议（IKEv2 / VLESS / Hysteria2）再试。

通用故障速查

客户端显示已连接，但所有网站都打不开

(1) DNS 没走代理：客户端里把 DNS 改成 1.1.1.1 / 8.8.8.8，或开"DNS 走代理"；
(2) 路由模式错了：选"规则"或"全局"，别选"直连"；
(3) 防火墙拦了：临时关掉杀软 / Windows 防火墙试试。

能上 Google 但 YouTube / Netflix 不能播

(1) DNS 污染：把客户端 DNS 改 Cloudflare (1.1.1.1)；
(2) Netflix 检测到 VPN IP：让管理员切换出口；
(3) App 缓存了旧 IP：清缓存 → 重启 App。

速度慢，看视频卡顿

(1) 测速：fast.com，应该 50Mbps+ 才能流畅 4K；
(2) 协议换 Hysteria2（QUIC 协议，跨洋稳定）；
(3) 时间：晚上 8~11 点跨洋拥堵，凌晨快一倍；
(4) 别用公共 WiFi 看 4K，5GHz 频段更好。

每隔几分钟断一次

(1) 客户端把"自动重连"打开；
(2) 协议改 IKEv2（自带 MOBIKE，切网络不断连）；
(3) 手机省电策略把 VPN 客户端加白名单（小米 / 华为常坑）。

订阅 URL 复制不上 / 粘贴失败

(1) 在 iOS 用 Safari 复制（其他浏览器可能不给剪贴板权限）；
(2) 长按 URL → "拷贝链接"；
(3) 实在不行，用二维码扫码导入。

更新订阅后节点全没了

多半是订阅 URL 失效（token 被管理员重置）。到 /signup.html 用新邀请码重新注册。

访问国内网站变慢

路由模式选"规则 (Rule)"而非"全局 (Global)"。规则模式会让国内站点直连。

客户端崩溃 / 闪退

(1) 升级到最新版；
(2) 卸载重装；
(3) 老机型（Android 5/6, iOS 13 以下）可能不支持，用 IKEv2 系统级方案。

隐私 / 安全 / 法律

管理员能看到我访问什么吗？

Vega VPN 默认 不记日志。技术上：服务器只转发加密流量，连接断开即销毁；不记录访问的域名 / URL / 流量内容。但管理员理论上可以"如果有意"打开抓包，所以请只对信任的管理员使用。

德国警察会找上门吗？

德国法律允许私人运营 VPN。只要不做违法事（盗版 / DDoS / 儿童色情等），不会有问题。管理员一般会忽略 abuse report，但严重违规（比如版权方告侵权）他可能会被迫披露使用者。

能用来做 P2P / BT 下载吗？

Vega 不禁，但出于"不给管理员惹麻烦"原则，请别下盗版。下 Linux ISO 之类合法 BT 没问题。

token 泄漏会怎样？

别人能蹭你的流量。月流量超限管理员会停服。专属链接千万别发群里。怀疑泄漏立刻找管理员重置 token。

我能转发链接给朋友吗？

不行。每个朋友自己用收到的邀请码到 /signup.html 注册，方便流量追溯和管理。

流量 / 配额

有流量上限吗？

家庭服务器月共享 20 TB 池。一般个人用户每月 50~200 GB 完全够。看 4K Netflix 一个月可能 100GB。

怎么看我已经用了多少？

打开 "我的账户"页面查（输你的订阅 token 看实时流量）。或客户端里"流量统计"页可看本地累计（不一定准）。

超流量了会怎样？

限速到 1Mbps 或直接停服，看管理员政策。

进阶 / 极客

能改 DNS 吗？

客户端里 DNS 默认是 Cloudflare 1.1.1.1。可以改成 Quad9 (9.9.9.9) / Google (8.8.8.8) / AdGuard (94.140.14.14)。建议保持走代理。

能给手机分应用代理吗？

v2rayNG / NekoBox / Verge 都支持"分应用代理"。指定只代理 Chrome / YouTube，其他 App 直连。

能在 Linux 服务器上跑（中转）吗？

可以。sing-box CLI + systemd 即可。详见 Linux 教程。

能加自定义节点吗？

你的订阅里多个协议节点（IKEv2 / VLESS / Hysteria2 / Trojan）已经提供。如果想加自己的 VPS 中转，联系管理员开通"双层代理"配置。

API / 编程接口？

订阅 URL 本身就是 API：GET /sub/{token} 返回 V2Ray 格式；?type=clash 返回 Clash 格式；?type=singbox 返回 sing-box 格式。可以 cron 自动拉。

  4. ipinfo.io 截图（如果能打开的话）

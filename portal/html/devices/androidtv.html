Android TV 盒子 / 智能机顶盒

小米 / Shield / Onn 4K Pro / 华为 / 天猫魔盒

通用思路

中等 5~10 分钟 装 v2rayNG APK

所有带 Android TV 系统的盒子（Android TV 9+ 或国产 Android 系统盒子）都可以通过侧载（sideload）安装 v2rayNG 或 NekoBox APK，把订阅导入，然后整机走 VPN，包括预装的 Netflix / YouTube / Disney+ App。

关键步骤：下载 APK → 用 U 盘 / 文件管理器装上 → 导入订阅 → 启动 VPN。

下载 v2rayNG arm64 (本地镜像 · TV 侧载) 下载 NekoBox arm64 (本地镜像) 原始 GitHub arm64-v8a 版 · 现代 TV 盒子首选 · 用 Send Files to TV 推到盒子
adb install v2rayng.apk USB 调试 / adb connect 盒子IP:5555 后执行

所有订阅都在「我的账户」里管理（含多个订阅时可自选）。点下面按钮跳过去复制 URL 或扫二维码。

去「我的账户」拿订阅

通用：v2rayNG for Android TV

  1. 在电视上装"Send Files to TV"（Play 商店搜）

    这是 TV 端官方的文件传送 App。同时在手机也装一个。

  2. 在手机浏览器下载 v2rayNG_x.x.x_arm64-v8a.apk

    从 GitHub Releases 拿最新版。

  3. 手机 Send Files to TV → 选 APK → 发送到电视

    电视和手机要在同一局域网。电视端会自动收到。

  4. 电视上打开"文件管理器" → 找到刚收到的 APK → 安装

    第一次会提示"未知来源应用"，去 设置 → 设备 → 应用 → 安全 → 未知来源 允许文件管理器。

  5. 电视上启动 v2rayNG → 右上角 + → 从剪贴板导入

    但 TV 上没办法直接复制订阅 URL。两种办法：
    (A) 用蓝牙键盘手敲；
    (B) 推荐：用 Sponsor 或 v2rayNG 内置二维码扫描，用手机显示订阅二维码（上面那个二维码），TV 扫码导入。

  6. 启动 VPN → 测试

    装个浏览器 App（Puffin TV / TV Bro）打开 ipinfo.io 验证。或直接打开 YouTube 看能不能播 4K。

各品牌差异

Nvidia Shield TV / Shield TV Pro

原生 Android TV，体验最佳。Play 商店里 v2rayNG / NekoBox 都能直接搜到（如果 Play 商店区域是美国）。开启"开发者选项 → 未知来源"后侧载也很顺滑。推荐方案 A：Play 商店直装。

Onn 4K Pro / Chromecast with Google TV (4K)

纯净 Google TV 系统。装"Downloader"（Play 商店搜）→ 输入 APK 下载直链 → 自动安装。或用 Send Files to TV。推荐 NekoBox（更省内存，盒子内存通常 2GB）。

小米盒子（国际版 Mi Box S / 4K Stick）

原生 Android TV，操作同上。国行小米盒子（MIUI TV）要先开"设置 → 账户与安全 → 安装未知来源" + 删掉小米的 App 商店推送，否则装好的 v2rayNG 第二天会被自动清理。

华为悦盒 / 海美迪 / 国产盒子

多数是 Android 9~11 魔改版。流程：

  1. 开发者模式

    "关于设备 → 版本号"狂按 7 下，开发者模式出现。

  2. 开 USB 调试 + ADB 安装

    电脑装 ADB，adb connect 盒子IP:5555 → adb install v2rayNG.apk。

  3. 盒子可能没"打开 App"按钮

    装 "应用启动器"（比如 ATV Launcher）才能进 v2rayNG 主界面。

天猫魔盒 / 当贝 / 创维等闭源系统

这些盒子改了 Android，自带 App 商店里没有 v2rayNG。流程：U 盘装 APK，然后用 当贝市场 / 沙发管家 跳到"我的应用 → 隐藏的应用"找到 v2rayNG 入口。部分严格机型禁用了侧载，建议改方案 B（路由器层），见下。

方案 B：路由器层 VPN（一劳永逸）

如果盒子装不了 APK，或者你家 4~5 台设备都要看 Netflix，把 VPN 装在路由器上整个家庭网络就都走代理了。详见 路由器教程。

常见问题

v2rayNG 装好但电视主界面找不到？

Android TV launcher 默认只显示"TV App"。装 "Sideload Launcher"（Play 商店搜）或 "ATV Launcher"，里面能看到所有侧载的非 TV App。

遥控器没法输入订阅 URL？

(1) 接 USB 键盘；(2) 用 Google TV 手机 App 当虚拟键盘；(3) 用手机显示二维码，TV 上 v2rayNG → 扫码导入（v2rayNG 6.0+ 支持摄像头扫码，盒子没摄像头则不行，回到法 (1)(2)）。

Netflix / Disney+ 显示"VPN 检测到，无法播放"？

家用 VPS 的 IP 通常已被 Netflix 标记。解决：(1) 换出口 IP（到 /setup.html 管理员可换 IP 池）；(2) 用住宅 IP 中转；(3) 改协议为 IKEv2 + 较冷门端口。Vega 默认配 Netflix-DE 友好出口。

盒子内存不够，v2rayNG 闪退？

用 NekoBox（更轻量）。或精简 v2rayNG 配置：设置里关掉 GeoIP / 路由模式改"全局"。

看 4K 卡顿？

(1) 测速达不到 25Mbps 卡 4K 正常；(2) 协议改 Hysteria2（基于 QUIC，跨洋大带宽更稳）；(3) 检查盒子的 WiFi 是否 WiFi 5/6 双频。
